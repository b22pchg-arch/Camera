ExifTool WASM riêng V125 - Sửa điền form metadata

Trang này không đăng ký Service Worker và không tự tải ExifTool từ CDN khi mở. V125 bỏ đường tải trực tiếp zeroperl.wasm vì package CDN không cung cấp file đó tại URL đơn giản; thay vào đó dùng bundle local đã build bằng Vite.
Vì sao V122 còn lỗi?
Log của anh báo https://cdn.jsdelivr.net/npm/@6over3/zeroperl-ts@1.0.10/zeroperl.wasm trả HTTP 404. Nghĩa là không thể giả định CDN có file WASM ở đường dẫn đó. Bản V125 yêu cầu build local để bundler tự resolve dependency @6over3/zeroperl-ts và copy WASM/asset đúng chỗ.

1) Chuẩn bị ExifTool local bundle

Chạy file build_exiftool_v124_local.ps1 hoặc build_exiftool_v124_local.cmd trong thư mục app trên máy có internet. Sau khi build xong, thư mục app cần có:
index.html
exiftool_wasm_tool_v125_fill_form_fixed.html
exiftool-vendor/
  exiftool-browser.es.js
  assets/...
